# 独立简历系统：个人先用，后续邀请灰度

## 当前范围

本阶段实现平台模型额度模式。用户自带模型 API 的模式留待第二阶段，当前没有浏览器输入模型密钥的功能。

后端首页 `/`、`/index.html` 和 `/resume.html` 都是简历系统；`/dashboard.html` 是岗位看板，支持相互跳转。

用户页面只包含「我的资料库」「定制简历」，后端地址由部署配置自动提供。旧版浏览器手动地址与遗留模型 Key 会清理，经历资料和资料备份不受影响。

## Windows 本地启动

需要 Python 3.11+，首次在源码目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[test]'
.\.venv\Scripts\python.exe scripts/local_setup.py
.\start.ps1
```

配置脚本以隐藏输入收取 DeepSeek Key。私有 `.env`、邀请 SQLite 和自用邀请码在源码目录旁的 `.resume-platform-local/` 中，均不在本 Git 仓库内。首次仅创建一个 7 天内可兑换的邀请码，不会覆盖已有配置。

如果暂时没有 Key，可执行 `scripts/local_setup.py --no-key`，之后再次运行不带此参数的命令补入 Key。默认模型名 `deepseek-flash` 可在私有 `.env` 调整，接口采用 DeepSeek 官方兼容格式：https://api-docs.deepseek.com/ 。

打开 `http://127.0.0.1:8000/`，从本机 `owner-invite.txt` 复制邀请码兑换，然后导入资料、填写 JD、生成、上传证件照、预览或下载 PDF。邀请码和 Key 不要提交到仓库或聊天。

个人和全平台每日默认均为 12 次模型 HTTP 尝试（北京时间重置），每次完整生成通常至少 3 次。失败重试计次；如需调整，在私有配置修改额度后重启。默认仅作为本地试用预算。

Windows 自动寻找系统宋体；Linux 指定 `QIUZHAO_RESUME_FONT` 或安装可嵌入 TrueType 宋体。照片是当前正式 PDF 的必填项。

## 独立 Cloudflare Pages 入口

保留已有看板项目。在新的 Pages 项目关联本仓库的本开发分支，设置：

- 构建命令：`python scripts/build_site.py --resume-only`
- 输出目录：`dist/resume-app`
- 构建环境变量：`QIUZHAO_PUBLIC_API_URL=https://实际后端域名`

构建只输出公开的 API 地址和看板地址，不读取或发布模型 Key。看板页保留 `resume.html` 跳转，简历页提供返回正式看板链接。后续正式独立站地址确定后可将看板链接更新为该地址。

后端运行账户的私有配置增加 `QIUZHAO_CORS=https://实际独立前端域名`（多个精确 Origin 以逗号分隔），然后重启。默认留空适用于后端同域页面。更换前端域名不会自动迁移浏览器资料，先导出 JSON，再到新站导入。

## 服务器运行

安装依赖后，使用受限的仓库外 `.env`，启动命令：

```bash
python -m agent.launcher --env-file /var/lib/resume-platform/llm.env
```

环境文件须包含模型 Key、Base URL、模型名、`QIUZHAO_ACCESS_DB`、平台额度和必要 CORS。可保留 systemd 现有 Environment 方式，继续运行 `python -m agent.server`；本改动不要求覆盖原有 SQLite 或重建用户。

后端仅监听回环地址；外部通过 HTTPS 代理或隧道接入。尚未提供服务器连接及固定地址时，不能完成线上部署和真实模型验收。
